# Olympic-Games-Performance-Analysis

## Overview

This project analyses Olympic Games data to identify patterns in athlete participation, medal achievements, gender representation and hosting trends across countries. Using data from Olympic athletes, medals, results and host countries, the project explores how countries perform at the Olympics, how medal counts differ by gender, the relationship between participation and success, the most successful Olympic sports and the distribution of Summer and Winter Olympic Games.

## How the Program Works

The project was developed in R using packages from the tidyverse, including dplyr, ggplot2, and stringr. Multiple Olympic datasets were loaded, cleaned and merged to create a consistent dataset for analysis. Missing values were removed, columns were renamed where necessary and the data was filtered and grouped to answer specific research questions. Summary statistics and visualisations were then created, including bar charts, line graphs, heat maps and pie charts. These visualisations were used to compare medal counts between countries and genders, analyse athlete participation trends, identify the most successful Olympic sports and examine patterns in Olympic hosting across Summer and Winter Games.
